# سامانه نوبت‌دهی پزشکی

## معرفی پروژه

سامانه نوبت‌دهی پزشکی یک سیستم آنلاین برای رزرو نوبت پزشک، مدیریت نوبت‌ها و ویزیت بیماران و یادآوری زمان مراجعه است.

## مسئله و نیاز کاربران

رزرو نوبت به روش سنتی ممکن است باعث اتلاف وقت، شلوغی مطب و فراموش شدن زمان مراجعه شود. این سامانه به بیماران کمک می‌کند به‌صورت آنلاین نوبت بگیرند و به پزشکان و مسئولان مطب امکان می‌دهد نوبت‌ها را بهتر مدیریت کنند.

## ویژگی‌های اصلی سامانه

* رزرو آنلاین نوبت: امکان مشاهده زمان‌های آزاد پزشک و رزرو نوبت
* مدیریت نوبت‌ها: ثبت، ویرایش، لغو و مشاهده نوبت‌ها
* مدیریت ویزیت بیماران: ثبت وضعیت مراجعه و مدیریت فهرست بیماران
* یادآوری بیمار: یادآوری زمان نوبت به بیمار
* مدیریت اطلاعات پزشکان: ثبت نام، تخصص و ساعات حضور پزشکان
* مشاهده سوابق نوبت: مشاهده نوبت‌های قبلی و آینده

## مخاطبان سامانه

* بیماران
* پزشکان
* منشی‌ها و مسئولان پذیرش
* مدیر سامانه
